# Hjalmar Widlund

Founder and operator in Stockholm. I built and ran a D2C e-commerce business in five European markets, with full responsibility for the P&L: product, purchasing, Shopify and conversion, paid acquisition, customer support and finance.

I work on the commercial side. When the business needs a tool that does not exist, I build it with Claude Code.

## Projects

**[shopify-volume-discounts](https://github.com/hjawid-dev/shopify-volume-discounts)**
A Shopify app for "buy more, save more" offers: a product page widget, a discount function that runs at checkout, and an admin UI. It runs entirely on Shopify, with no server.

**[shopify-landing-page-generator](https://github.com/hjawid-dev/shopify-landing-page-generator)**
Turns a short brief with copy and images into a product landing page for five markets. Price, stock and rating are read from Shopify instead of typed in, and publishing is built so that it cannot change a live product page by accident.

**[support-triage](https://github.com/hjawid-dev/support-triage)**
Sorts customer emails from five markets, flags the ones that need a person, and drafts replies from the store policy. Includes a test set that measures accuracy and cost per email.

**[logic-test-trainer](https://github.com/hjawid-dev/logic-test-trainer)**
A practice tool for the matrix logic tests used in hiring. It generates unlimited puzzles, adapts the difficulty to your answers and names the mistake behind each wrong answer. Checked by a suite that generates 12,000 puzzles per run.
